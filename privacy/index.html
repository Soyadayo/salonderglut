プライバシーポリシー

最終更新: 2026年11月14日

Haus Tacorari(以下「私たち」)は、このサイトと、私たちが自分たちの YouTube チャンネルの運営に使う道具での情報の扱いを、次のとおり定めます。

このサイトについて

このサイトは GitHub Pages で公開している静的なページです。私たちはアクセス解析や Cookie、外部の追跡の仕組みを入れておらず、訪問者の個人情報を集めていません。GitHub がサイトの提供のために記録する情報は、GitHub のプライバシーに関する声明に従って扱われます。

YouTube の投稿道具について

私たちは、YouTube API サービスを使って、制作記録の動画を自分たちのチャンネル(Haus Tacorari)に上げ、公開日時を予約する道具を使っています。この道具は次のとおり動きます。

  • 使う人は、私たち自身だけです。ほかの人のアカウントにはつながりません。
  • 読み書きするのは、Haus Tacorari のチャンネルの情報(動画のアップロード、タイトル、説明、公開日時、サムネイル)と、チャンネル名の確認だけです。
  • ログインの情報(アクセストークン)は、私たちの作業用のコンピューターの中だけに保存し、外部に送ったり共有したりしません。
  • 取得した情報を、広告、販売、第三者への提供に使いません。
  • アクセスの許可は、Google アカウントのセキュリティ設定(https://myaccount.google.com/permissions)からいつでも取り消せます。

この道具は YouTube API サービスを使っています。YouTube の利用規約(https://www.youtube.com/t/terms)と Google のプライバシーポリシー(https://policies.google.com/privacy)も適用されます。
